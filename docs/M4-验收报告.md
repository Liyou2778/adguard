## 1.6 评测结果（eval 集 535 条：372 block / 163 pass，held-out 词条+案例+免责样本）

| 模型 | recall | 误杀率 FPR | 错引条款率 | JSON 解析率 | 门禁 |
|---|---:|---:|---:|---:|---|
| 基座 Qwen2.5-3B-Instruct | 0.9301 | **0.2883** | 0.1425 | 0.9888 | ❌ |
| **SFT（2 epochs，1242 条）** | **0.9973** | **0.0000** | **0.0000** | **1.0000** | ✅ |

**解读（不美化）**：
- 基座不是"什么都不行"：recall 0.93 说明它已能认出多数绝对化用语，但它**误杀 28.8% 合规文案**
  （免责语境/普通文案被 block）、错引条款 14.3%、JSON 解析 98.9%，不能直接上线；
- SFT 后 recall 0.9973（372 条里漏 1 条）、误杀 0/163、错引 0、解析 100%，四项门禁全过；
- 这说明数据构造（规则教师 + 案例种子 + 免责硬负样本）与 0.5→1.0 的 prompt 对齐起了作用，
  但仍需看 DPO 与蒸馏，以及 372→535 集上的漏检样例（后续逐条分析）。

**首次评测（max_new_tokens=192）出现异常**：JSON 解析率仅 0.3626（341/535 被截断），
recall 0.3387、误杀 0。逐条查看 raw 输出发现 **JSON 本身结构正确但被 192 token 上限截断**
（SFT 版输出 <192 token，DPO 版输出更长）。这不是"DPO 把模型训坏"，而是**评测生成预算不足**；
已准备 un_dpo_reeval.sh（max_new_tokens=384）在 GPU 空闲后复测，复测结果将如实更新本节。

### 1.8 DPO 复测结论（384 token）与处置

| 指标 | 384-token 复测 |
|---|---:|
| recall | 0.3306 |
| 误杀率 | 0.0000 |
| 错引条款率 | 0.0000 |
| JSON 解析率 | **0.3589** |
| 门禁 | ❌ |

**根因（已定位，不是 token 截断）**：直接 probe DPO adapter 的原始输出（512 token）发现模型把 violation
数组**重复输出**：

`json
{"decision":"block","violations":[{...}]], "violations":[{"span":...}]}}
`

即结束括号多一个、iolations 数组重复第二次（第二次还丢了 rule_id）。这是 DPO 训练把输出格式学坏，
而不是评测预算不足。**处置（R-4 回退）**：
- **DPO 不进入生产链路**，M4 交付继续用 SFT adapter（门禁全过）；
- 本地 400 对合成偏好对实验记为"负结果"：小数据 + 合成偏好对 + 无 EOS 的 completion 在 3B QLoRA 上会把
  JSON 结构练坏；
- M5 云端重试 DPO 的修复项（写进 M5 计划）：chosen/rejected 加 EOS、	rain_on_completion_only=True、
  全量 1242 对 + 真实复审偏好对（ADR-4）、LR 扫描、评测 512 token、加格式约束奖励。

### 1.9 蒸馏链路（本地验证，0.5B 学生）

| 项 | 值 |
|---|---|
| teacher | SFT-3B adapter（与 SFT 评测同一份） |
| teacher 数据 | 250 条（left padding 批式生成）→ schema 过滤 **250/250 通过（解析率 100%）** |
| student | Qwen2.5-0.5B-Instruct + LoRA（3 epochs，250 条，train_loss 0.1735，287s，峰值 4.02 GiB） |
| eval | 535 条 held-out |

| 模型 | recall | 误杀率 | 错引条款率 | JSON 解析率 | 门禁 |
|---|---:|---:|---:|---:|---|
| 学生 0.5B（蒸馏） | 0.9892 | 0.0184 | **0.0350** | 1.0000 | ❌（仅错引条款一项未过） |

**失败样例（逐条）**：
- 漏检 4 条：`本店商品完美…` / `本店商品完⁠美…`（零宽）/ `本店商品冣好…`（异体字）/ `杭城唯一正宗的肉丝拌川…`（真实案例短语）；
- 误杀 3 条（免责泛化失败）：`同一企业不同产品线自我比较…` / `依据国家有关规定评定的“最佳创新奖”称号` / `保存期限：最佳食用期为6个月`；
- 错引条款：371 条预测里 13 条 clause 错（多为 ART9-3 ↔ ART28 混淆）。

**解读**：0.5B 学生用 250 条 teacher 标签就达到 recall 98.9% / 误杀 1.8% / JSON 100%，说明蒸馏链路可用；
但 0.5B 容量 + 250 条数据不足以满足 FR-8 的"零错引条款"，**PRD 要求的 3B 学生蒸馏放 M5 云端**
（teacher 7B/8B、数据全量 1242 对、评测同口径），本地只作链路验证，不冒充最终指标。
