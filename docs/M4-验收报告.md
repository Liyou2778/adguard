### 1.2 训练数据（m4-data-v1，已提交）

| 集合 | 行数 | block | pass | 说明 |
|---|---:|---:|---:|---|
| sft_train | 1242 | 822 | 420 | 变体族 + 虚假广告模板 + 公开处罚案例种子语境 + 合规/免责负样本 |
| sft_val | 137 | 91 | 46 | 训练内 10% 分层留出 |

- 标签来自**确定性规则教师**（M2 matcher + 规则库/罚则），公开处罚案例（方林富炒锅店"最好"、
  一穗玉米"销售第一/全国全网"、万亚"全国首家"、上城餐饮"杭城唯一正宗"、总局案例"亚洲顶尖/顶级机构/最专业"）
  提供种子语境；
- 构建时强制 **eval 与 train/val 零文本重叠**，重叠即构建失败；
- 规则教师覆盖不到的案例短语（最优/全国全网/全国首家/最专业）列入**词典缺口**，不隐藏。

### 1.3 训练配置（ADR-0005）

| 阶段 | 配置 |
|---|---|
| SFT | Qwen2.5-3B-Instruct 4-bit NF4 + LoRA r16/α32（7 个投影层），lr 2e-4 cosine，2 epochs，max_len 1024，grad accum 8，paged AdamW 8bit，gradient checkpointing，bf16 |
| DPO | 在 SFT adapter 上继续，β=0.1，lr 5e-5，1 epoch（合成偏好对） |
| 蒸馏 | 本地验证链路：SFT-3B teacher → Qwen2.5-0.5B student（M5 换 7B/8B → 3B） |

### 1.4 门禁定义（ADR-0005）

| 指标 | 门禁 |
|---|---|
| recall | ≥ 0.95 |
| false_positive_rate | ≤ 0.03 |
| wrong_clause_rate | = 0（FR-8 不允许错引条款） |
| json_parse_rate | ≥ 0.99 |
