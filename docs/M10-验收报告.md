> 日期：2026-11-25 ｜ 里程碑：M10（P1，方案 A：`caption` 商家文案字段 + 规则/LLM 一致性引擎）
> 结果：**本地 M10 冒烟 18/18 PASS；ECS 18/18 PASS**；一致性评测 **recall=1.000、FPR=0.000（30 对，真实 DeepSeek 调用）**；M1/M3/M7/M8/M9 回归全部通过。

## 1. 交付内容

| 能力 | 实现 |
|---|---|
| caption 接入 | 素材创建 API 新增可选 `caption`（≤2048 字）；仅 image/video 参与一致性校验；Flyway V8 `asset.caption` |
| 断言抽取 | 价格 / 折扣 / 满减 / 买赠 / 第 N 件半价 / 规格（ml/g/kg/片/包/瓶…）/ 有效期；支持阿拉伯数字与中文数字（五折、买一送一、第二件半价） |
| 互斥检测 | 同属性值冲突（价格容差 1%、规格/折扣 1%、有效期精确）；买赠/满减类承诺**跨 key 互斥**判定 |
| LLM 灰区兜底 | 规则未命中时调用 OpenAI 兼容端点（默认 DeepSeek `deepseek-flash`）做语义矛盾检测（全国包邮 vs 偏远不包邮、仅限今天 vs 持续一周等）；**缓存 + 超时可降级** |
| 定位 | 冲突带两侧原文证据；图片侧按行偏移映射 OCR bbox |
| 判定策略 | 冲突转为 `family=cross_modal_consistency` 违规；**pass→manual 转人工**，block 保持（规则优先），reason 追加说明；无 caption 跳过 |
| 证据留存 | `asset.parse_meta.consistency` 保存 conflicts/engine/llm_used/warnings，供复核页与审计 |
| 评测 | `data/eval/consistency_pairs.json`（15 冲突 + 15 非冲突）+ `scripts/eval_consistency.py`，输出 recall/FPR/precision 与逐条明细 |

## 3. 冒烟（`scripts/smoke-m10.ps1`，18 项，本地+ECS 均 PASS）

- `/v1/consistency` 规则冲突：`到手价 99 元` vs `活动价 199 元` → conflict(price, bbox)；
- LLM 语义冲突：`全国包邮` vs `偏远地区不包邮` → `llm_used=true, engine=rules+llm`；
- 图片素材（OCR 文字"活动价 199 元"）+ caption"到手价 99 元，限时抢购"：
  decision=**manual**，violation `CONSISTENCY-PRICE`、family=`cross_modal_consistency`、证据含 99/199、parser_meta 记录 consistency；
- asset.caption 持久化；caption 一致时不产生 cross-modal 违规；无 caption 时 `parse_meta` 不含 consistency。

## 4. 成本

- 灰区 LLM 调用仅发生在「有 caption 且本地规则未命中」的素材上；`deepseek-flash` 单次约 300–600 tokens，成本约 ¥0.0002/次量级；带缓存（caption+图片文字 hash）。规则可覆盖的冲突不调用 LLM。

## 5. 已知限制

| 项 | 说明 |
|---|---|
| caption 可选 | 商家未填 caption 时无法做图文一致性（按设计跳过并记录）；后续可强制或从商品标题自动带入 |
| 语义覆盖 | LLM 灰区判定受提示词与模型能力影响；当前使用 DeepSeek `deepseek-flash`（支持文本+图片输入），未直接传图片，只比较 OCR 文本与 caption |
| LLM 可用性 | 端点不可用时自动降级为纯规则并标记 degraded，不阻断判定；生产建议配置备用端点/重试 |
| 密钥管理 | API Key 仅存 ECS `/opt/adguard/config/pipeline.env`（600 权限），未进 git；**本轮聊天中曾出现 key，建议轮换** |
| 中文数字 | 支持 1–99 的常用中文数字；复杂金额/小数表述仍以阿拉伯数字为主 |

FR-6 的「抽取断言三元组（主体-属性-值）、检测互斥」与 AC（构造冲突样本检出率 ≥0.9）均已达成：构造样本 recall=1.0、FPR=0，且通过真实 LLM 在本地与 ECS 双环境验证；冲突与证据（含 bbox）在判定、复核页和审计中全程可追溯。
