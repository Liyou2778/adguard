## 二、检索评测（主指标）

> 完整报告（自动生成）：[M3-检索评测](M3-检索评测.md)
> 指标 JSON：`services/pipeline-py/data/retrieval/m3_retrieval_metrics.json`

### 2.1 方法（防自嗨设计）

1. 索引：M2 解析出的 **33 条条款**（11 条 article + 22 条 item），每条带 `revision=sha256(text)`；
2. 多路召回：字符二元组 BM25（稀疏） + bge-small-zh-v1.5 向量（sqlite-vec KNN） + 规则/条文号 + 家族词典；
3. 融合：RRF（k=60）；重排：6 个可解释特征加权（权重在 dev 上调）；
4. 查询集：
   - **material 手写集 55 条**（营销文案问题，如"全网最低价，错过再等一年"），
     按奇偶切 **dev 28 / test 27**，权重只在 dev 上调，**报告只报 test**；
   - penalty 手写集 8 条（问"怎么罚"），报告但不设门禁；
   - 从条文自动生成的 clause 集 66 条（词汇重叠高，只作 sanity）；
5. 命中判定：acceptable = 目标条款 + 其父条款（item 级命中即可；article 级算条款级命中），
   指标 Recall@1/3/5、MRR、NDCG@10。

### 2.2 结果（held-out material test，27 条）

| 配置 | R@1 | R@3 | R@5 | MRR | NDCG@10 |
|---|---:|---:|---:|---:|---:|
| bm25_only | 55.6% | 66.7% | 66.7% | 0.627 | 0.663 |
| dense_only | 14.8% | 55.6% | 63.0% | 0.331 | 0.470 |
| hybrid_rrf | 55.6% | 70.4% | 74.1% | 0.653 | 0.717 |
| **hybrid_rerank（采用）** | **66.7%** | **88.9%** | **92.6%** | **0.761** | **0.810** |

- penalty 集：R@5 = 87.5%（8 条，规则式意图识别，未设门禁）；
- clause 生成集：R@5 = 98.5%、NDCG@10 = 0.966；
- 调参后权重（dev 网格搜索）：`bm25 0.35 / dense 0.30 / family 0.20 / rule_exact 0.10 / item_level 0.05 / role_fit 0.00`
  （role 已经在候选过滤阶段生效，重排权重取 0 是数据选择的结果）。

**解读**：纯向量在中文短查询上明显弱（R@1 14.8%），BM25 词面强但语义弱；混合 + 重排把 R@5 从 66.7%
提到 92.6%，这就是 PRD「多路召回 + rerank」的实证价值。

## 三、增量索引 / revision 一致性（PRD 明确要求）

- 每条条款在存储中带 `revision = sha256(text)`；
- 检索命中后与**源侧当前 revision** 比对：不一致 → 丢弃，并返回 `dropped_stale` 与 warning；
- 单元测试：`test_stale_revision_is_dropped`（制造"索引旧、源已变"场景，断言该条款不再返回）；
- rule judge 测试：`test_stale_index_never_cites_stale_revision`（判定不得引用旧 revision）；
- 运行时：`/v1/retrieve` 冒烟 `dropped_stale=0`（常态无脏数据）；
- 增量更新：`RetrievalService.upsert_clause / delete_clause` 单测覆盖索引更新后检索立即生效。

对应 WeKnora 的 `TestRerankEnrichmentDropsChangedChunkRevision` 语义（见 ADR-0004）。
