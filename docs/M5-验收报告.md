1. **修复 TODO-M5-1**（错引 3 条 → 0），重跑 535 条门禁；否则不做灰度切换；
2. 用户创建 **P2 独立 ECS**（2C4G / 40G ESSD / 杭州 / 同 VPC / 独立安全组 / 密钥对），部署走 `deploy/ecs/`（systemd stable+canary、nginx 10%→50%→100%、一键回滚）；
3. RDS MySQL `adguard` 库与账号、OSS bucket/前缀（可复用现有桶，独立前缀）；
4. GPU 推理服务按量启停：`ADGUARD_MODEL_JUDGE_URL` 指向 vLLM；规则命中直接返回，仅 manual 流量调模型（实测约 5%）；
5. 灰度期观测指标：`/metrics` 的判定分布、模型降级次数、P99 延迟、错误率；回滚演练一次并记录。
