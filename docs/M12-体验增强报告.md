## 1. 交付内容

### 1.1 账号安全（FR-10 增强，用户选择"无 IdP，本地账号增强"）

- **首次登录强制改密**：管理员创建/重置的账号带临时密码，JWT 中写入 `pwd_change=true`；除 `/auth/me`、`/auth/password` 外所有控制面接口与网关素材接口返回 **403 PASSWORD_CHANGE_REQUIRED**；改密后旧 token 仍被拦，需重新登录（新 token 才放行）。
- **登录锁定/限速**：连续 5 次密码错误锁定账号 15 分钟（DB 计数，跨请求生效）；锁定期间正确密码也拒绝；管理员重置密码会同时解锁。
- **审计**：登录失败、锁定、改密、管理员重置均写 `audit_log`；管理员创建/重置账号时 `must_change_password=true`。
- **管理台**：登录后检测 `must_change_password` 直接弹出改密表单；顶部「改密」入口；用户列表显示「临时密码」标记。
- **SSO**：按用户选择 **暂不接**（无 IdP）；已预留扩展点（JWT/角色模型可直接映射 OIDC claims），未来提供 issuer/client_id/secret/redirect_uri 即可接入。TOTP 列已在 V9 预留，本轮未启用（如实说明）。

### 1.2 落地页 Headless 截图（可选能力）

- pipeline 渲染模式二选一：
  - `ADGUARD_PLAYWRIGHT=1`：Playwright 无头浏览器渲染 → 截全页 PNG → RapidOCR + 版面分析 → **元素/行/bbox 与图片素材一致**；
  - 默认 `dom-only`：抓 HTML 抽可见文本，无像素坐标，`degraded=true` 并写明原因（ECS 2C4G 默认）。
- 浏览器不强制下载 Chromium：本地使用系统 Edge（`ADGUARD_PLAYWRIGHT_CHANNEL=msedge`），也支持 Chrome/Chromium 或 `ADGUARD_PLAYWRIGHT_EXECUTABLE`。
- 截图可配置落盘目录（`ADGUARD_SCREENSHOT_DIR`），`meta.screenshot_path` 记录路径；截图内容不返回 API（避免响应过大），审计可后续接 OSS。
- **本地实测**：真实渲染 `https://example.com` → `render=screenshot`、`degraded=false`、OCR 18 行（含多语言文本）、bbox 完整、截图 51KB；经网关上传 landing_page 素材 → `parse_status=parsed`、judgment=pass。
- **ECS**：未安装浏览器（2C4G 内存保护），按设计走 `dom-only` 并标记 degraded；M12 冒烟按预期断言 `dom-only`。

### 1.3 视频 ASR（faster-whisper tiny, CPU）

- 语音转写（可选 `ADGUARD_ASR_ENABLED=1`）：ffmpeg 抽 16k 单声道 wav → faster-whisper（tiny/int8，2 线程）转写 → 文本以 `[asr] ...` 追加到解析文本，**参与规则判定**；分段/语言/引擎写入 `parse_meta.meta.asr`。
- 默认模型 tiny（约 75MB，CPU 友好）；可通过 `ADGUARD_ASR_MODEL=base/small` 升级。
- **ECS 真实视频验证**：上传含中文语音的 mp4 → 解析文本 `[asr] 全王最低價 現實強調 買到舊時轉動`（tiny 存在同音字误差）、`language=zh`、`degraded=false`、`parse_status=parsed`，规则判定为 **block**（语音中出现"最低價"）。
- 资源：ECS 常驻内存约 2.1GB/3.6GB（RapidOCR+ClamAV+ASR tiny），可用约 1.5GB；ASR 模型按需加载。

## 4. 已知限制（如实）

| 项 | 说明 |
|---|---|
| ECS 无截图 | 2C4G 不装 Chromium；需要截图的部署可为 worker 增加 4G+ 内存/独立节点，否则 DOM-only（已标记 degraded） |
| ASR 精度 | tiny 模型存在同音字/断句误差，仅作为**补充证据**；重要场景建议 base/small 或人工复核 |
| 截图持久化 | 目前仅落本地路径；未上传 OSS（接口不返回截图内容），后续可接入对象存储与复核页预览 |
| SSO / TOTP | 本轮未实现（无 IdP；TOTP 列已预留），需要时按 OIDC/TOTP 方案接入 |
| 登录限速 | 账号级锁定在 CP 单实例内通过 DB 生效；多实例共享 DB 也生效；未做 IP 级分布式限速（可在 nginx/WAF 层加） |
