01 系统定位与核心链路

面向广告主/平台的市场营销素材合规审核：规则为权威、模型为二审，每条违规可追溯到条款、罚则区间、原文 span/bbox；支持多模态素材、图文一致性、申诉回流、多租户配额与账单。

接入层
Web/API → nginx 灰度 → Go Gateway（JWT/API Key、配额、分片上传、病毒扫描、解析编排、审计）
↓
控制面
Java Control Plane：规则库/不可变快照 · 用户/角色/首次改密 · 申诉复核 · 配额/账单/审计
↓
智能面
Python Pipeline：归一化 → BM25+Dense+RRF 检索 → 规则匹配 → 条款检索 → 模型二审；图文一致性（规则+LLM 灰区）；OCR/ASR/落地页解析
↓
数据/运行
MySQL RDS · Redis · OSS/S3 · SQLite 索引
ECS systemd · ClamAV · RapidOCR · faster-whisper · vLLM 7B（可选）

02 核心能力

  • 规则与快照：规则库、草稿→激活→灰度，判定绑定不可变快照，可复现、可回滚。
  • 检索判定：BM25 + 向量 + RRF + 可解释 rerank；规则命中 + 条款检索，违规必带 rule_id/条款/罚则。
  • 多模态：图片 OCR+版面 bbox；视频关键帧 OCR+语音 ASR；落地页 DOM/截图；ClamAV 病毒扫描。
  • 图文一致性：caption vs 图片文字，断言抽取 + LLM 语义灰区，冲突转人工复核。
  • 运营闭环：商家申诉→复核→DPO 偏好对；多租户配额（超限 429）、成本归集、CSV/中文 PDF 账单。
  • 工程与安全：JWT/BCrypt/API Key；首次登录强制改密、5 次失败锁定；SSRF 防护、审计日志、灰度回滚。

04 PRD 覆盖与边界（如实）

已完成：P0/P1 全部功能（FR-1～FR-13）：素材接入、解析、规则/检索/判定、条款证据、多模态、图文一致性、申诉回流、多租户配额/成本/账单、规则热更新、训练与评测。

  • 召回天花板：规则+检索对 535 条 gold-block 召回 93.01%，当前主要提升杠杆是规则/检索覆盖，而非替换模型。
  • ECS 不跑 headless 截图：2C4G 默认 DOM-only 并标记 degraded；截图能力已在本地 Edge 实测通过，需要时换 4G+ 渲染节点开启。
  • ASR：tiny 模型 CPU 可用但有同音字误差，作为补充证据；可升级 base/small。
  • 7B 混合未切生产：安全指标达标，但质量门禁未过，按原则保留 rule 后端。
  • 可用性与身份：单 ECS + RDS 基础版（无跨可用区 HA）；无 IdP，SSO 未接；TOTP 列已预留。
