## 恢复步骤（重开实例后，在 WorkBench 终端执行）

### 1. 修 venv + 装训练栈 + 续传模型 + 重启流水线

```bash
apt-get update -qq && apt-get install -y -qq python3-venv python3-pip
rm -rf /root/adguard-m5/venv
python3 -m venv /root/adguard-m5/venv
source /root/adguard-m5/venv/bin/activate
python --version
pip install -q --upgrade pip
pip install --no-cache-dir --progress-bar off -i https://repo.huaweicloud.com/repository/pypi/simple --trusted-host repo.huaweicloud.com \
  torch==2.5.1 transformers==4.46.3 peft==0.13.2 trl==0.12.2 datasets==3.1.0 \
  accelerate==1.1.1 bitsandbytes==0.44.1 sentencepiece protobuf httpx numpy==1.26.4 pyarrow==16.1.0
cd /root/adguard-m5/models/qwen2.5-7b-instruct
for f in config.json generation_config.json model.safetensors.index.json model-00001-of-00004.safetensors model-00002-of-00004.safetensors model-00003-of-00004.safetensors model-00004-of-00004.safetensors tokenizer.json tokenizer_config.json vocab.json merges.txt; do
  curl -fL --retry 3 --continue-at - --max-time 3600 -o "$f" "https://modelscope.cn/models/Qwen/Qwen2.5-7B-Instruct/resolve/master/$f"
done
du -sh /root/adguard-m5/models/qwen2.5-7b-instruct
echo STAGE1_DONE >> /root/adguard-m5/logs/stage1.log
pkill -f run_rest.sh 2>/dev/null; sleep 2
nohup bash /root/run_rest.sh > /root/adguard-m5/logs/run_rest.log 2>&1 &
echo RESTARTED
```

### 2. 确认训练开跑

```bash
tail -5 /root/adguard-m5/logs/run_rest.log
tail -5 /root/adguard-m5/logs/stage2_sft.log 2>/dev/null
nvidia-smi --query-gpu=memory.used,utilization.gpu --format=csv,noheader
```

看到 `=== RUN cloud_stage2_sft ===` 和 `it/s` 进度即成功。

### 3. 训练完成后取结果

```bash
ls /root/adguard-m5/reports/m5/
cat /root/adguard-m5/reports/experiments/sft-qwen25-7b-qlora-cloud-v1/metrics.json
cat /root/adguard-m5/reports/m5/api-eval-vllm-7b-sft-535.json 2>/dev/null
```

把 JSON 内容/截图发回，我更新 M5 报告并决定是否继续 DPO/压测。

## 本地侧恢复（用户电脑开机后）

1. 启动 WSL 保活（否则 MySQL 反复冷启动）：

```powershell
Start-Process -FilePath "wsl.exe" -ArgumentList @("-d","Ubuntu","-u","root","--","sleep","infinity") -WindowStyle Hidden
```

2. 启动本地三服务（可选，做回归冒烟时用）：`scripts\run-control-plane.ps1` / `run-pipeline.ps1` / `run-gateway.ps1`。
3. 检查 GPU 空闲与 git 状态：`wsl -d Ubuntu -u root -- nvidia-smi`；`git log --oneline -3`。
