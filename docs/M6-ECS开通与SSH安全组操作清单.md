# M6 P2 ECS / SSH / RDS 开通清单（一步一步，照做即可）

> 你确认：截图里 `i-bp-redacted`（203.0.113.13）是 **P1，保持不动**；P2 到 M6 再新建。
> 本文就是"M6 时你要在阿里云控制台点哪些按钮"的操作单，以及每一步要给我的信息。
> 原则：P1 与 P2 **不同实例、不同安全组、不同库、不同 Redis**，验收时逐条演示。

## 第 1 步：新建 P2 实例（约 3 分钟）

控制台 → 云服务器 ECS → 创建实例：

| 项 | 选择 |
|---|---|
| 付费方式 | **按量付费**（不演示可停机） |
| 地域 | **华东1（杭州）**（与 P1/RDS 同地域，走内网） |
| 规格 | `ecs.e-c1m2.large`（2 vCPU / 4 GiB） |
| 镜像 | **Alibaba Cloud Linux 3.2104 LTS 64位** |
| 系统盘 | ESSD Entry **40 GiB** |
| 网络 | 与 P1 同 VPC / 同交换机 |
| 安全组 | **新建** `sg-adguard`（见第 3 步规则） |
| 登录凭证 | **密钥对**（见第 2 步） |
| 实例名称 | `adguard-p2`（便于识别） |

创建后记下：**实例 ID、公网 IP、主私网 IP**（三个都发我）。

## 第 2 步：创建密钥对（约 1 分钟）

控制台 → ECS → 网络与安全 → 密钥对 → 创建密钥对：

1. 名称：`adguard-p2-key`
2. 创建后浏览器会**自动下载一次 `.pem` 私钥**（只这一次机会）
3. 把文件保存到：`C:\Users\Liyou\keys\adguard-p2-key.pem`
4. 告诉我：`C:\Users\Liyou\keys\adguard-p2-key.pem`（我本地读取，不读内容、不外传）
5. 若创建实例时选了该密钥对，则 SSH 可直接用；若实例已创建，可在实例详情 → 绑定密钥对

> 企业规范：**禁用密码登录**，只允许密钥。密钥文件不要提交到 git（`.gitignore` 已忽略 `*.pem`）。

## 第 3 步：安全组规则（约 2 分钟）

新建安全组 `sg-adguard`，入方向只放：

| 端口 | 来源 | 用途 |
|---|---|---|
| 22/tcp | **你的公网 IP/32** | SSH（查你当前 IP：浏览器搜 "ip"） |
| 8080/tcp | **你的公网 IP/32** | P2 网关（演示/冒烟） |
| ICMP | 你的 IP | ping 排障 |

**不要**对公网开放：8081（控制面）、8090（流水线）、3306（MySQL）、6379（Redis）、9000（MinIO）。
出方向默认全部（内网访问 RDS/OSS）。

## 第 4 步：RDS 建库 + 账号（约 3 分钟）

RDS 控制台（复用现有实例）→ 数据库管理：

1. **创建数据库**：库名 `adguard`，字符集 `utf8mb4`
2. **创建账号**：账号 `adguard`，密码用强密码（保存好，不要发我明文；我会让你在 ECS 的配置文件里填）
3. **授权**：账号 `adguard` 授权 `adguard` 库 **读写**
4. **白名单**：把 **P2 ECS 的主私网 IP** 加入 RDS 白名单（不是公网 IP）
5. 给我：**RDS 内网地址**（形如 `rm-xxx.mysql.rds.aliyuncs.com:3306`）

> 密码不需要告诉我：M6 部署时我会让你把它写进 ECS 上的 `/opt/adguard/config/*.env`（chmod 600），
> 或者你自己在服务器上编辑该文件。

## 第 5 步：OSS（对象存储）二选一

| 方案 | 操作 | 需要你给我 |
|---|---|---|
| A. 复用现有桶 + 前缀隔离（推荐） | 在现有桶建 `adguard/` 前缀；创建 RAM 子账号，策略只允许 `adguard/*` 读写 | RAM AccessKey/Secret（或 STS 临时凭据） |
| B. 先不用 OSS | ECS 本地 MinIO 容器（M6 期间也能跑通，但非生产形态，验收如实标注） | 无需 |

## 常见坑（提前避开）

- 安全组没放行你的公网 IP → SSH 超时；先确认来源 IP 是**当前**出口 IP
- RDS 白名单填了公网 IP → 连接超时；要填 ECS **主私网 IP**
- 密钥文件在 Windows 上权限过宽 → SSH 报 `UNPROTECTED PRIVATE KEY`；用 `icacls` 收紧
- 2C4G 内存：control-plane 1G 堆 + pipeline ~1G + gateway/redis/nginx ≈ 0.5G，总约 3.2G，接近上限；
  部署后我会实测 RSS，超限就按预案降级（hashing embedder / 缩小 JVM 堆）
