## 4. 部署中发现并修复的问题（真实记录）

| # | 问题 | 处理 |
|---|---|---|
| 1 | ECS 上 Docker Hub 不可达，redis 镜像拉取失败 | `setup-ecs.sh` 增加 apt/dnf redis-server 回退；ECR 上实际使用 apt redis |
| 2 | Ubuntu 缺 `python3-venv` → pipeline venv 创建失败（`No module named uvicorn`） | 安装 python3-venv 并重建 venv；`setup-ecs.sh` 已补装该包 |
| 3 | 部署包内 pipeline unit 缺 `PYTHONPATH`（旧包）→ `No module named adguard_pipeline` | 安装最新 unit（`Environment=PYTHONPATH=/opt/adguard/current/pipeline/src`）并重启 |
| 4 | 部署包内旧版 switch-canary 无 access_log/`max_fails` 修复 | 替换为仓库最新脚本，重新生成 nginx 配置 |
| 5 | nginx 首次安装时配置写入后未 reload，8080 未监听 | `setup-ecs.sh` 增加 reload；线上执行 reload 后 8080 正常 |
| 6 | 公网 8080 起初不通 | 安全组补充 TCP 8080 入方向规则（用户操作）后公网 200 |
