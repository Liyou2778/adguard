# M9 验收报告：FR-13 多租户配额 + 成本归集 + 账单导出

> 日期：2026-11-25 ｜ 里程碑：M9（P1）
> 结果：**本地 M9 冒烟 18/18 PASS；ECS 18/18 PASS**；M1/M3/M7/M8 回归全部通过。

## 1. 交付内容

| 能力 | 实现 |
|---|---|
| 租户隔离加固 | 网关新增 JWT 校验（tenant 来自 token）与服务 API Key（自动化）；admin/reviewer token 不得调用素材 API |
| 每日配额 | `tenant.daily_quota`（权重点数）+ Redis 每日计数器；`billing_price.quota_weight` 作为唯一权重来源（text=1/image=2/video=5/landing_page=3） |
| 超限拒绝 | `POST /api/v1/assets`、落地页创建在超限时返回 **429 QUOTA_EXCEEDED + Retry-After**；停用租户 403 TENANT_DISABLED |
| 成本归集 | 每次判定写 `usage_record`（weight/cost_micro/billed_date/asset_type/judgment_id），`judgment.cost_micro` 同步落价目表成本 |
| 用量查询 | 商家 `GET /api/v1/usage?from&to`；管理员 `/admin/usage`、`/admin/billing/summary` |
| 账单导出 | `GET /admin/billing/export.csv`（UTF-8 BOM，Excel 直开）与 `export.pdf`（中文月度账单，OpenPDF + wqy-zenhei 字体） |
| 价目表 | Flyway V7 `billing_price`，默认单价可后台调整/直接 SQL 调整；人民币、micro-CNY 精度 |
| 降级策略 | Redis 不可用时配额 fail-open 并告警（保证判定可用），账单仍以 usage_record 为准 |

## 2. 验收证据

### 2.1 冒烟（`scripts/smoke-m9.ps1`，18 项，本地 + ECS 均 PASS）

- 创建 quota=3 的租户；连续 3 次 text 提交成功（weight=1），**第 4 次 429**，带 `Retry-After`，错误码 `QUOTA_EXCEEDED`；
- 停用租户 → 提交 **403 TENANT_DISABLED**；重新启用并把配额改为 5 → 生效；
- demo-platform 图片/文本素材判定后：`judgment.cost_micro=100`（text），`GET /api/v1/usage` 返回 calls≥1、cost≥100；
- 账单汇总总额 >0；CSV 含 BOM 与真实行；PDF magic bytes `%PDF` 校验通过（中文账单）。

### 2.2 成本口径（默认价目表，micro-CNY）

| code | 单价（元） | 配额权重 |
|---|---|---|
| judge.text | 0.0001 | 1 |
| judge.image | 0.0005 | 2 |
| judge.video | 0.003 | 5 |
| judge.landing_page | 0.001 | 3 |
| consistency.image | 0.0015 | 0（不占配额，计入成本预留） |
| consistency.video | 0.0025 | 0 |

> 金额为内部成本归集口径，实际商务结算以合同为准（账单页已注明）。

## 3. 关键设计

- **权重单源**：`billing_price.quota_weight` 同时被网关配额和账单使用，避免"配额口径与计费口径不一致"。
- **幂等**：`usage_record` 以 `judgment_id` 去重，worker 重投递/崩溃恢复不会重复计费。
- **多租户可见性**：`/api/v1/usage` 的 tenant 取自 token；跨租户查询仅 admin。
- **Fail-open 边界**：Redis 故障只放宽配额，不放宽账单——判定成功即记账。

## 4. 已知限制

| 项 | 说明 |
|---|---|
| 配额口径 | 按**素材提交**计（weight 点数），不是按 token/耗时；视频/落地页解析成本通过权重近似 |
| 日界 | 计数器按 UTC 日界重置；如业务需要本地时区日界可后续加配置 |
| 计费精度 | 规则后端无 token 成本，单价为内部定价；接 vLLM 后可扩展按 token 计费 |
| PDF 依赖字体 | ECS 需安装 `fonts-wqy-zenhei`（已装）；缺字体时返回 503 PDF_FONT_MISSING |
| 租户自助充值 | 配额由管理员调整，无在线购买/套餐计费 |

## 5. 结论

FR-13 的「租户隔离、调用配额、超限拒绝、成本归集、账单导出」全部落地并通过本地与云上验收；网关同时完成生产级 JWT/API Key 鉴权加固。
