# ADR-0005：模型工程（M4）的模型选择、数据与训练配置

- 状态：已接受（M4）
- 日期：2026-11-22
- 关联：PRD ADR-4 / ADR-5、R-1 / R-3 / R-4 / R-5；技术设计 §5（模型工程）
- 上游：ADR-0003（归一化/条款解析）、ADR-0004（检索与规则判定）

## 背景

M4 要在 **RTX 4060 Laptop 8 GB + 15 GB RAM** 的本地机器上交付可复现的训练链：
标注集 → SFT → DPO → 蒸馏 → 门禁。PRD 的目标模型是 7B/8B（云 GPU），本地只能跑
3B 级 QLoRA。同时没有任何人工标注语料，只有 M2/M3 的规则与公开处罚案例。

## 决策

### 1. 本地基座：Qwen2.5-3B-Instruct（QLoRA 4-bit）

- 中文指令跟随、许可证（Apache-2.0）与社区成熟度适合本项目；
- 3B 4-bit 权重约 1.8 GB，SFT 峰值显存预计 6–7 GB，8 GB 可跑；
- 7B/8B 全量 SFT/DPO 按 PRD R-1 放 M5 云 GPU（gn7i）执行，**同一套代码与配置**，
  只改 model_id/批次即可复现。

### 2. 标注：规则教师 + 公开处罚案例种子 + 执法指南免责样本（R-3 方案）

- 违规标签来自确定性规则栈（M2 matcher + M3 条款/罚则映射），可复现、可审计；
- 公开行政处罚案例（[方林富炒货店](http://news.cnr.cn/native/gd/20160324/t20160324_521699785.shtml)、
  [河南一穗玉米/市场监管总局典型案例](http://www.maoming.gov.cn/zwgk/zwzl/zdlyxxgkzl/spypaqxxgk/wfgg/content/post_1460051.html)、
  [杭城唯一正宗（上城区市监局）](https://news.foodmate.net/2024/12/705736.html) 等）
  提供真实广告语种子语境；
- 免责样本严格按 2023 年《广告绝对化用语执法指南》第五/六条构造，标为 pass（假设广告主可举证）；
- **规则教师覆盖不到的案例短语单列"词典缺口"**（最优/全国首家/最专业/全国全网），不混入标签。

### 3. 数据划分：按词条分折 + 留出案例/模板/免责样本，构建时强制零文本重叠

- 违规正样本：M2 变体族 + 虚假广告模板 + 案例种子语境；
- `sha256(term) % 4 == 0` 的词条进 eval，其余进 train/val（实体级隔离）；
- 留出 1 个处罚案例、2 个免责样本、2 个合规模板只出现在 eval；
- 构建失败即中断（eval 与 train/val 文本重叠直接报错）——防泄漏是构建器责任，不是训练脚本。

### 4. 训练：SFT（QLoRA）→ DPO → 蒸馏三步，全部留实验记录

| 阶段 | 配置 | 说明 |
|---|---|---|
| SFT | LoRA r=16 α=32，lr 2e-4，2 epochs，max_len 1024，paged AdamW 8bit + gradient checkpointing | 输出严格 JSON（decision + violations + clause + span） |
| DPO | 在 SFT adapter 上继续，β=0.1，lr 5e-5，1 epoch | 当前用**合成偏好对**（chosen=金标，rejected=漏检/错条款/过度拦截）；PRD ADR-4 的真实复审偏好对随 M6 复核流程上线后替换 |
| 蒸馏 | teacher=SFT-3B → student=Qwen2.5-0.5B（本地验证链路）；M5 改为 7B/8B → 3B | 蒸馏数据=teacher 生成，eval 集不变，用于验证"掉点可量化" |

### 5. 门禁定义（不降标）

| 指标 | 定义 | 门禁 |
|---|---|---|
| recall | 金标 block 样本中被正确判 block 的比例 | ≥ 0.95 |
| false_positive_rate | 金标 pass 样本中被误判 block 的比例 | ≤ 0.03 |
| wrong_clause_rate | 模型输出的 violation 中 clause 与金标不一致的比例 | **= 0**（FR-8 不允许错引条款） |
| json_parse_rate | 输出可被 schema 解析的比例 | ≥ 0.99 |

评测集另有 semantic_unknown（规则与模型都可能漏的语义改写）与 exemption 泛化样本，
**只报告不设门禁**，避免用不可达指标自欺。

## 后果

**正面**
- 8 GB 本地就能完成"数据→SFT→DPO→蒸馏→评测"全链路，云 GPU 只用于放大规模；
- 每次实验都有 config + 数据 sha256 + metrics（`reports/experiments/`）；
- 训练目标包含条款与原文 span，直接服务 FR-8。

**负面 / 已知限制**
- 规则教师标签的上限就是规则上限：语义改写、未见变体不会自动进训练集；
- 合成 DPO 偏好对不是真实复审裁决（ADR-4 的完整落地要等 M6 复核数据）；
- 3B 在 CPU/4-bit 下的推理延迟与成本只作 M5 压测的输入，不是最终结论；
- 本地 0.5B 学生只验证蒸馏链路，不代表 PRD 要求的 3B 学生效果（M5 上云验证）。

## 被否方案

| 方案 | 否掉原因 |
|---|---|
| 本地直接训 7B | 8 GB 显存不可能（PRD R-1 已确认），强上只会浪费时间 |
| 全参数微调 3B | 8 GB 放不下优化器状态；LoRA 已足够验证链路 |
| 用公有云 API 造标签 | 违反私有化约束；规则教师即可覆盖已知族 |
| 直接把规则引擎输出当模型输出（不训练） | 无法泛化到语义改写，且 PRD 要求可定制模型 |
| 评测集与训练集同分布混用 | 指标虚高，违反本项目"不美化数字"原则 |
