# M6 依赖创建清单（用户控制台操作）

> M6 上线需要 3 个云资源：**ECS**（已给步骤）、**RDS MySQL**、**OSS Bucket + RAM**。
> 本文档给"点哪里、填什么"，创建完把信息发我即可；所有密钥只存在服务器，不进 git。

## 1. RDS MySQL（推荐；M6 生产形态）

1. 控制台 → **云数据库 RDS** → 创建实例：
   - 计费：**按量付费**
   - 地域：**华东1（杭州）**（与 ECS 同地域，走内网）
   - 引擎：**MySQL 8.0**
   - 系列/规格：**基础版，1核2G**（演练够用；以控制台可选项为准）
   - 存储：**20 GB**
   - VPC：与 ECS **同一 VPC**（购买页可选）
   - 交换机：与 ECS 同可用区
2. 创建完成后：
   - 「账号管理」→ 创建账号：`adguard`，密码用控制台随机生成（**只发我一次**）；
   - 「数据库管理」→ 创建数据库：`adguard`，字符集 `utf8mb4`，授权账号 `adguard`；
   - 「白名单」→ 添加 ECS 的**内网 IP**（或把 ECS 安全组加入白名单，二选一）；
   - 「数据库连接」→ 记录 **内网地址**（形如 `rm-xxx.mysql.rds.aliyuncs.com:3306`）。
3. 把 3 个值发我：内网地址、账号、密码。（Flyway 迁移会在 control-plane 首次启动时自动执行 V1–V3）

> 成本：最低配按量约每小时几毛钱（以控制台报价为准），M6 演练数小时总成本 <¥10。

### 备选（省钱、但偏离生产）：ECS 本机 Docker MySQL

如果临时不想开 RDS，可以在 ECS 上用 `docker run mysql:8.0`（`setup-ecs.sh` 不包含，需手动），
网关 DSN 指向 `127.0.0.1:3306`。**部署记录必须写明这是偏离项**，M6 验收以 RDS 为准。

## 2. OSS Bucket + 访问凭据

1. 控制台 → **对象存储 OSS**：
   - 可复用现有桶（如 `copilot-artifacts-ly`）→ 新建目录前缀 `p2/`；
   - 或新建 Bucket：`adguard-assets-example`，地域杭州，**私有**读写，标准存储。
2. 记录 **Endpoint**：
   - ECS 访问用**内网 Endpoint**（同地域免流量费）：`oss-cn-hangzhou-internal.aliyuncs.com`
   - 浏览器/外部访问用公网 Endpoint：`oss-cn-hangzhou.aliyuncs.com`
3. RAM 访问凭据（最小权限）：
   - 控制台 → **RAM 访问控制** → 用户 → 创建用户（如 `adguard-oss`）→ 勾选「使用永久 AccessKey」→ 保存 AccessKey/Secret（只发我一次）；
   - 给该用户授权：**自定义策略**，只允许 `oss:PutObject/GetObject/DeleteObject/ListObjects` 于 `acs:oss:*:*:adguard-assets-example/p2/*`（或复用桶的 `p2/*` 前缀）。
   - （可选更优：STS 临时凭据；M6 先用 RAM 子账号，记录为后续优化项。）

## 3. 网络与安全组

| 资源 | 方向 | 规则 |
|---|---|---|
| ECS 安全组 `sg-adguard-p2` | 入 | SSH(22)（临时 0.0.0.0/0）；TCP 8080（公网灰度入口）；ICMP |
| ECS 安全组 | 出 | 全放行（默认） |
| RDS 白名单 | 入 | ECS 私网 IP 或 ECS 安全组，端口 3306 |
| OSS | — | RAM 策略控制，不走安全组 |

RDS 内网地址: rm-xxxx.mysql.rds.aliyuncs.com:3306
RDS 账号/密码: adguard / ********
OSS Bucket: adguard-assets-example（或 copilot-artifacts-ly，前缀 p2/）
OSS 内网 Endpoint: oss-cn-hangzhou-internal.aliyuncs.com
