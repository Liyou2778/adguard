# M6 真实网关 + nginx 灰度演练（本地，无 ECS）

> 目的：在 ECS 创建前，用**真实 Go 网关进程**（部署包中的二进制同源产物）验证
> nginx `split_clients` 灰度、《切换脚本语义》、cutover 与回滚流程，而不是只用 stub 上游。
> 日期：2026-11-25 ｜ 环境：Windows + Docker（nginx:1.27-alpine）+ 两个真实网关进程

## 1. 拓扑

```
curl (带 X-Tenant-Id)
  -> nginx :18085 (docker, 与 deploy/ecs/setup-ecs.sh 同结构配置, split_clients)
       -> stable  http://host.docker.internal:8082   (真实 gateway.exe)
       -> canary  http://host.docker.internal:8083   (真实 gateway.exe)
```

两个网关进程都连本地真实依赖：WSL MySQL :3307、Redis :6379、MinIO :9000、control-plane :8081、pipeline :8090。

## 2. 结果

| 档位 | 请求数 | stable | canary | 实测比例 |
|---|---:|---:|---:|---|
| 10% | 200 | 181 | 19 | **9.5%** |
| 50% | 100 | 52 | 49 | **48.5%** |
| 100% | 100 | 1（切换瞬间旧请求） | 100 | **100%** |
| 0% | 100 | 100 | 1（切换瞬间旧请求） | **0%** |

- 两个网关 `healthz=200`；
- **cutover 演练**：nginx 先切 0% → 停止 canary 进程 → 公网 healthz **200**（无 5xx 窗口）；
- **回滚演练**：重启 canary → 50% → 0% → healthz **200**。

> 计数里 1 条偏差来自"切换配置瞬间的 in-flight 请求"，属正常；比例与配置一致。

## 3. 结论

1. `deploy/ecs` 的 nginx 配置语义在**真实网关**上成立：租户粘性分流、0/10/50/100 切换正常；
2. cutover 顺序（先切 0% 再停 canary）经实测无中断；
3. 回滚路径可用；
4. 仍待真实 ECS 验证：systemd 拉起、RDS/OSS 凭据、公网安全组、nginx 日志轮转。
