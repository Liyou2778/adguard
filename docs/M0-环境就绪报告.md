## 六、回滚手册（环境恢复到 2026-11-22 20:38 之前）

```powershell
# 1) 恢复用户级环境变量
$b = "$env:USERPROFILE\tools\.env-backup"
[Environment]::SetEnvironmentVariable('JAVA_HOME', (Get-Content "$b\JAVA_HOME.user.bak" -Raw).Trim(), 'User')
[Environment]::SetEnvironmentVariable('Path', (Get-Content "$b\Path.user.bak" -Raw).Trim(), 'User')

# 2) 恢复 Maven settings（若存在备份）
Copy-Item "$b\settings.xml.bak" "$env:USERPROFILE\.m2\settings.xml" -Force

# 3) 删除便携工具链（可选，共约 338 MB）
Remove-Item "$env:USERPROFILE\tools\jdk-21" -Recurse -Force
Remove-Item "$env:USERPROFILE\tools\apache-maven-3.9.16" -Recurse -Force

# 4) 还原 Go 代理（可选）
go env -u GOPROXY; go env -u GOSUMDB
```

> 未删除任何原有 JDK / 软件；Docker Desktop 只是被启动，未改其配置。
