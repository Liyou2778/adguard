## 2. 起检索+判定服务（:8090）

```powershell
cd C:\Users\Liyou\Documents\deepseek\adguard\services\pipeline-py
.\.venv\Scripts\python -m uvicorn adguard_pipeline.api:app --host 127.0.0.1 --port 8090
```

启动后第一次 `/v1/index/status` 会触发索引构建（33 条款，BGE 向量，约 2–5 秒）：

```powershell

# {"clauses":33,"index_version":"cf60...","embedder":"BAAI/bge-small-zh-v1.5","dimensions":512,...}
```

## 3. 起网关（规则判定后端）

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-gateway.ps1
```

环境变量（脚本已带默认值）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `GATEWAY_JUDGE_BACKEND` | `rule` | `rule`=调 Python `/v1/judge`；`stub`=M1 占位判定 |
| `GATEWAY_PIPELINE_URL` | `http://127.0.0.1:8090` | 流水线服务 |
| `GATEWAY_PIPELINE_TIMEOUT` | `10s` | 超时后降级 manual |

```powershell

curl.exe -s -X POST http://127.0.0.1:8090/v1/retrieve -H "Content-Type: application/json" ^

```

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 检索日志提示 `falling back to hashing embedder` | 向量模型不在 `.tmp/models/bge-small-zh-v1.5` | 执行第 1 步下载模型；或明确用 `--embedder hashing` 做 smoke（指标不可与正式报告比较） |
| `Model not found` / 下载超时 | HF 不可达 | 用 `--endpoint https://hf-mirror.com`；或手动把模型文件放到模型目录 |
| 判定一直 manual，reason 含 `unavailable` | 网关连不上 8090 | 检查流水线服务与 `GATEWAY_PIPELINE_URL` |
| 判定 block 但条款不对 | 条款库/revision 变更后未重建索引 | `POST /v1/index/rebuild` |
| `dropped_stale > 0` | 源侧条款已更新但索引未重建 | 重建索引；这是 revision 守卫在正常工作 |
| 图片素材 manual | OCR 未实现（M4） | 预期行为 |
